# Lark IM Readonly

Use this skill when the user asks to inspect Feishu/Lark IM data without sending new messages.

## Preconditions

The machine must have `lark-cli` installed and authenticated:

```bash
lark-cli auth login
```

If authentication is missing or expired, ask the user to authenticate before continuing.

## Allowed Use

Use read-only `lark-cli im` commands for:

- Finding or inspecting chats
- Listing chat members
- Searching existing messages
- Downloading message resources such as files or images
- Inspecting message metadata needed to answer the user

Examples:

```bash
lark-cli im +chat-members-list --chat-id "<chat-id>"
lark-cli im +messages-resources-download --message-id "<message-id>" --file-key "<file-key>" --type file
```

## Forbidden Use

Do not run `lark-cli im` commands that send, reply, forward, delete, update, receive, or listen for messages.

Forbidden examples:

```bash
lark-cli im +messages-send ...
lark-cli im +messages-reply ...
lark-cli im +messages-receive ...
```

In a Feishu-triggered Pi run, the pi-remote-feishu transport is the only normal channel that sends the final answer back to the current chat. For local files generated by the agent, use `send_file_to_chat`.
