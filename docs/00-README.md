## 读者建议

- **第一次接触**：按顺序读到第 4 步即可形成整体认识，第 5 步按需精读。
- **面试/讲项目**：重点看 `07-设计决策与权衡.md`，里面整理了可讲的亮点和取舍。
- **二次开发**：重点看 `08-运行测试与二次开发.md` 和对应的模块精读。
- **纯原理派**：只看 02、03、04、07 四篇，不读代码也能懂架构。

> 源码根目录的 `ARCHITECTURE.md` / `ARCHITECTURE.zh-CN.md` 是**设计稿**（规划怎么做），
> 本目录是**实现精读**（实际代码怎么写的），两者互补。
